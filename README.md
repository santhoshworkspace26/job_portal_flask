# Job Portal Website 🚀

A full-stack Job Portal web application built using Flask, MySQL, HTML, CSS, and JavaScript.

## Features

- User Registration & Login
- MySQL Database Integration
- Responsive UI Design
- Dark/Light Theme Toggle
- Job Listings
- Application System
- Resume Upload Support
- Flask Backend
- Authentication System

## Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Flask (Python)

### Database
- MySQL (XAMPP/phpMyAdmin)

## Installation

1. Clone repository

```bash
git clone https://github.com/santhoshworkspace26/job_portal_flask.git
```

2. Open project folder

```bash
cd job-portal-flask
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Start XAMPP MySQL

5. Run Flask server

```bash
python app.py
```

6. Open browser

```txt
http://127.0.0.1:5000
```
